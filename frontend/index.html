HOW IT WORKS

The pipeline

Every upload runs through the same six always-on steps.

01

Upload & extract

Drop in a project ZIP. It's safely extracted with zip-slip protection.

02

Detect language

File extensions are scanned to identify the project's dominant language.

03

Static analysis

Semgrep scans for bugs, insecure patterns, and code-quality issues.

04

Dependency scan

pip-audit / npm audit check dependencies against known CVEs.

05

AI explanation

A local Ollama model explains each finding and suggests a fix — grounded, not free-form.

06

Dashboard

Severity breakdown, quality score, and export to CSV.
